# Hallzy Cinematic Detailed Pack (Java Edition)

This repository now ships a **fully reworked, texture-heavy cinematic resource pack** for Minecraft Java 1.21.x.

It is built to behave like a normal downloadable pack from sites like CurseForge:
- no shader include hacks,
- no OptiFine requirement,
- obvious visual changes (blocks, water/lava, skies, moon/sun, HUD, colormaps, vignette).

## Install on macOS (Java Edition)

1. Open Finder
2. Press `Cmd + Shift + G`
3. Go to: `~/Library/Application Support/minecraft/resourcepacks`
4. Delete old Hallzy packs
5. Copy in one matching `.zip` (do not extract)
6. Launch Minecraft Java and enable it in Resource Packs

## Troubleshooting

- Red text "Incompatible" means wrong file for your exact MC version.
- "Broken" usually means stale/duplicate pack files in `resourcepacks`.
- Keep only one Hallzy zip installed while testing.
