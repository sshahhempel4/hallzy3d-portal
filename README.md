# Hallzy Vanilla Shader Pack (Java Edition)

Vanilla-friendly shader-style resource packs for **Minecraft Java 1.21.x**.

## No OptiFine required

These are normal Java resource packs that override Minecraft's built-in shader include files.

## Why there are multiple files

Minecraft 1.21 changed shader and pack internals several times (pack format and shader include signatures), so one universal file can be marked broken/incompatible on some patch versions.

This repo now ships **exact-version builds**.

## Install on macOS (Java Edition)

1. Open Finder.
2. Press `Cmd + Shift + G`.
3. Paste: `~/Library/Application Support/minecraft/resourcepacks`
4. Copy the matching `.zip` into that folder. (Do **not** extract it.)
5. Launch Minecraft Java.
6. Open **Options -> Resource Packs** and enable it.

## If it still says broken/incompatible

1. Remove all old Hallzy zips/folders from `resourcepacks`.
2. Keep only one matching zip for your exact game version.
3. Temporarily disable all other packs.
4. Relaunch Minecraft and test again.
